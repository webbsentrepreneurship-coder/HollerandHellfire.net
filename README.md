# Holler & Hellfire

The official website of the Holler & Hellfire Universe, a static site served by GitHub Pages.

Live at: https://webbsentrepreneurship-coder.github.io/HollerandHellfire.net/

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home: the universe and how its properties connect |
| `books.html` | Books & Stories, including KIRO |
| `characters.html` | Characters |
| `lore.html` | Lore & Codex |
| `gallery.html` | Gallery (artwork with artist credit) |
| `records.html` | H&H Records |
| `creators.html` | About the Creators |
| `shop.html` | Shop |
| `nexus.html` | H&H Nexus (future fan hub) |
| `contact.html` | Contact & Socials |

Shared styling is in `assets/style.css`; the mobile menu script is `assets/site.js`.

## Editing

Dashed boxes marked "to be added" are placeholders for approved content
(book details, character profiles, codex entries, artwork, music, links).
Replace each one with the real content. Put images in `assets/images/` and
always include the artist credit next to artwork.

The navigation menu is repeated at the top of every page, so a new page
needs a link added to each file's `<nav>`.

## Publishing

Settings → Pages → Build and deployment → Source: "Deploy from a branch",
branch `main`, folder `/ (root)`.
