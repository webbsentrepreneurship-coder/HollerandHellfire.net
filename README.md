# Holler & Hellfire

Static site served by GitHub Pages.

- `index.html` is the whole site; edit the placeholder text in it.
- `.nojekyll` tells GitHub Pages to serve the files as-is.

## Publishing

In the repo on GitHub: **Settings → Pages → Build and deployment**, set
**Source** to "Deploy from a branch", pick the branch and `/ (root)`, and save.
The site appears at https://webbsentrepreneurship-coder.github.io/HollerandHellfire.net/
